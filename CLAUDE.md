# web-losHermanos
#falta diseno mobile  
Sitio web estático para el restaurante/negocio "Los Hermanos".

## Stack

- HTML + Tailwind CSS (CDN)
- Browser-sync para desarrollo local (`npm run dev` → `http://localhost:3000`)
